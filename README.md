# Electrical Installation Design & Calculation

**Author:** Alex Aquino Sala  
**Degree:** B.Sc. in Electronic and Automatic Engineering  

## 📌 Project Overview
This repository contains the complete design, calculation, and documentation for the electrical installation of a [tipo de edificio, e.g., industrial warehouse / residential building / solar PV system]. 

The project encompasses power distribution calculations, switchgear sizing, voltage drop verification, and budget estimation, strictly adhering to the Spanish Low Voltage Electrotechnical Regulation (REBT).

## 🛠️ Software & Tools Used
*   **CYPE (CYPELEC REBT):** Core software used for electrical calculations, single-line diagrams, and compliance checks.
*   **FIEBDC (.bc3):** Standard format used for the bill of quantities and budgeting.
*   **AutoCAD / PDF:** Used for viewing and generating the final electrical floor plans.

## 📁 Repository Structure
*   `[Fabrica_carga_concentrada_V2].elec$` / `[Fabrica_carga_concentrada_V2].elece`: Native CYPE project files containing the complete mathematical model and electrical parameters.
*   `[Fabrica_carga_concentrada_V2].bc3`: FIEBDC database file containing the itemized budget and material costs.
*   `[Memoria_proyecto (conbinacion)].pdf`: Technical report exported from CYPE justifying the calculations.
*   `/Planos/`: Folder containing the exported floor plans and single-line diagrams in [PDF/DWG] format.

## 👁️ How to View This Project
To explore the native files, you will need the CYPE software suite installed on your machine or view the **pdf** of the proyect
